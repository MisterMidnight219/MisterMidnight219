## MidnightLabs

[MidnightLabs](https://github.com/MisterMidnight219/Midnightlabs) is my living cybersecurity and infrastructure lab journal. It preserves both the early simulations and the current physical home-lab build rather than presenting only polished outcomes.

The project combines:

- Network segmentation and firewall policy
- Virtualization and self-hosted infrastructure
- Storage, logging, and observability
- Windows Server and Active Directory foundations
- Defensive-security investigation
- AI-assisted system analysis with explicit human approval

### Current system map

| System | Role |
|---|---|
| **Midgar** | OPNsense gateway, routing, segmentation, and policy |
| **Ellie** | Proxmox compute and virtualization |
| **Index Prime** | TrueNAS/ZFS persistence, storage, and planned log retention |

The operating philosophy is **observable over magical**: favor systems that are locally controllable, inspectable, integratable, and recoverable.

## How I Work

1. **Study** the underlying concept.
2. **Build** it in a controlled environment.
3. **Break and recover** until the failure modes make sense.
4. **Document** the evidence, not merely the successful ending.
5. **Publish** what another person can inspect.
